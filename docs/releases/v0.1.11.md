Note for Android v0.1.11 — 노트를 옆으로 넘겨 보는 페이지 넘기기를 더한 업데이트입니다(iPad v0.1.8과 같은 기능 수준).

## 새 기능

- **옆으로 넘기기**: 한 화면에 한 페이지씩 보이고, 손가락으로 옆으로 밀면 다음/이전 페이지로 넘어갑니다.
  - 살짝 튕기면 한 장씩 넘어가고, 천천히 끌다 놓으면 더 많이 보이는 페이지에 맞춰 멈춥니다.
  - 페이지는 화면에 통째로 들어오게 맞춰지고, 가로로 돌리면 다시 맞춰집니다.
  - 확대한 상태에서는 그 페이지 안에서 자유롭게 움직이고, 옆 페이지 쪽으로 충분히 끌어 놓으면 그 페이지로 넘어갑니다.
  - 펜은 지금처럼 바로 쓰고, 손가락으로 그리기 모드에서는 두 손가락으로 넘깁니다.
  - 노트 화면의 더 보기(⋯) › "옆으로 넘기기", 또는 설정 › 필기 › "페이지 넘기기"(세로 스크롤 · 옆으로 넘기기)에서 바꿉니다.
    기본값은 지금처럼 세로 스크롤입니다.

노트 파일 형식은 바뀌지 않아 iPad 앱과 그대로 함께 쓸 수 있습니다.
