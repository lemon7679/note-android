Note for Android v0.1.3 — 연필 질감과 렌더링 성능을 개선한 업데이트입니다. 엔진은 note-core InkEngine 0.2.0입니다.

## 개선

- **연필이 더 자연스럽고 부드러워졌습니다**: 흑연이 획을 따라 밀도로 쌓여 가장자리가 둥글고 부드럽고, 같은 곳을 다시
  그으면 실제 연필처럼 진해집니다. 종이 결을 둥근 돌기로 바꿔 자글자글한 점 대신 벨벳 같은 질감이 납니다.
  예전에 쓴 연필 필기도 새 질감으로 보입니다(파일은 그대로).
- **형광펜이 많은 페이지에서 확대·축소, 스크롤, 지우개가 끊기지 않습니다**
  - 잉크 래스터화를 다시 작성해 넓은 형광펜의 중복 계산을 없앴습니다(형광펜이 겹친 페이지에서 타일 렌더링 20~100배 빠름).
  - 페이지 타일을 백그라운드 스레드에서 그립니다. 화면 가운데 타일부터 그리고, 그동안 이전 타일을 늘려 보여 줍니다.
  - 확대 배율을 단계(약 1.26배 간격)로 나눠, 조금만 핀치해도 전부 다시 그리던 것을 없앴습니다.
  - 정밀 지우개로 긴 형광펜을 지울 때 자른 부근만 다시 그립니다(프레임당 다시 그리기 약 150배 감소).
  - 지우개 한 번의 실행 취소 기록을 "원래 획 → 남은 조각" 하나로 합쳐 메모리를 덜 씁니다.
- **자동 저장과 페이지 썸네일이 필기를 막지 않습니다**: 저장할 내용을 스냅숏으로 잡아 백그라운드에서 직렬화·저장하고
  표지 썸네일을 만듭니다. 저장 순서는 그대로 보장됩니다(노트를 닫을 때는 진행 중인 저장까지 마친 뒤 닫음).

노트 파일 형식은 바뀌지 않아 iPad 앱과 그대로 함께 쓸 수 있습니다.
