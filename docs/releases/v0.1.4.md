Note for Android v0.1.4 — Synology NAS로 노트가 올라가지 않던 문제를 고친 업데이트입니다.

## 고침

- **Synology(DSM)에 노트 파일이 업로드되지 않던 문제**: 새 노트의 폴더는 NAS에 생기지만 그 안의 `document.json`,
  `thumbnail.png`, 페이지 파일이 모두 `DSM 오류 401`로 실패했습니다. File Station 업로드 요청을 Synology 예제·iPad 앱과
  같은 형식으로 직접 만들도록 바꿨습니다(필드 → 파일 순서, 파트마다 붙던 `Content-Length` 헤더 제거).
  DSM이 수정 시각(`mtime`) 필드를 거부하면 그 필드 없이 다시 올리고, 이후로는 보내지 않습니다.
- **"Software caused connection abort"**: 앱이 백그라운드로 갈 때 동기화를 시작해, Android가 백그라운드 앱의 네트워크를
  끊으면서 전송이 중간에 끊겼습니다. 이제 백그라운드 진입 시에는 동기화를 시작하지 않고(편집 내용은 기기에 저장되어 있다가
  다음 실행·복귀·편집 때 올라감), 끊긴 전송은 잠시 뒤 최대 두 번 다시 시도합니다.

## 개선

- 동기화 오류에 노트 이름과 경로(`선형대수.inknote/document.json`)를 함께 보여 주고, DSM이 알려 준 세부 정보를 덧붙입니다.
  400~404 같은 File Station 오류도 뜻을 풀어 표시합니다.

이미 실패로 남아 있던 파일은 업데이트 후 첫 동기화에서 다시 올라갑니다(기록은 업로드가 성공해야만 바뀌므로 잃는 데이터는 없습니다).
노트 파일 형식은 바뀌지 않아 iPad 앱과 그대로 함께 쓸 수 있습니다.
