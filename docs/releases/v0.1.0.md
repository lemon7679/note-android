Android용 필기 앱 **Note**의 첫 릴리스입니다. [note-ipad](https://github.com/lemon7679/note-ipad)의 설계·디자인과 로직을 그대로 옮겨,
NAS(Synology · WebDAV · SMB 폴더)에 노트와 PDF를 두고 Android 태블릿·휴대폰에서 오프라인으로 쓰다가 양방향으로 동기화합니다.
필기는 [note-core](https://github.com/lemon7679/note-core) InkEngine(C++)을 NDK로 빌드해 그립니다. 노트 파일 형식이 iPad와 같아
같은 NAS 폴더를 iPad와 함께 쓸 수 있습니다.

## 설치

- `Note-0.1.0.apk`를 받아 설치합니다(설정 › 보안에서 "출처를 알 수 없는 앱 설치" 허용). 또는 `adb install Note-0.1.0.apk`.
- 요구 사항: Android 10 이상. 태블릿(가로 840 dp 이상)에서는 사이드바가 고정되고, 휴대폰에서는 서랍 메뉴로 바뀝니다.
- 스타일러스(S Pen, USI 펜 등)로 쓰는 것을 기본으로 합니다. 손가락으로 쓰려면 편집기 › 더 보기 › "손가락으로 그리기".

## 주요 기능

**NAS 중심 파일 관리**
- Synology DSM(File Station API, 2단계 인증), WebDAV(QNAP · TrueNAS · Nextcloud 등), 시스템 파일 선택기로 고른 SMB/USB 폴더
- 같은 네트워크의 NAS 자동 검색, 연결 테스트, NAS 폴더 선택, 자체 서명 인증서 고정(TOFU), 암호는 Android 키스토어로 암호화
- 3-way 양방향 동기화: 바뀐 페이지만 전송, 충돌 시 "이 기기 유지 / NAS 유지 / 둘 다 보관", PDF는 열 때 다운로드,
  자동·Wi-Fi 전용 동기화, 대량 삭제 방지 안전장치
- NAS 전체 보기, 노트를 닫을 때 PDF 함께 저장(옵션), 폴더 · 이동 · 복제 · 이름 변경 · 즐겨찾기 · 최근 문서 · 검색 · 휴지통

**필기**
- 볼펜 · 만년필 · 연필 · 붓펜 · 캘리그라피 · 마커 · 형광펜, 필압 · 기울기, 엔진 예측 입력
- 그리고 멈추면 도형, 글씨 보정, 손떨림 보정, 정밀/획 지우개, 스타일러스 지우개 끝 · 옆 버튼으로 지우기
- 올가미: 이동 · 크기 조절 · 복사/붙여넣기(페이지 간) · 색 변경 · 줄 정렬 · 글씨 다듬기
- 텍스트 상자 · 이미지 · 레이저 포인터, 종이 7종, 페이지 목록 · 책갈피, 노트 전체 실행 취소, 두 손가락 탭 실행 취소

**PDF**
- PDF 뷰어(썸네일 · 스크러버 · 확대 · 문서 내 검색(Android 15+)), "필기 시작"으로 원본은 그대로 두고 필기 노트 생성
- PDF 내보내기(필기는 벡터), 페이지 이미지 내보내기

## 이 빌드에 대해

- 이 저장소의 GitHub Actions에서 note-core와 함께 빌드한 릴리스(R8 최적화) APK입니다.
- 같은 커밋을 CI가 Android 에뮬레이터(태블릿 · 휴대폰)에서 실행해, 주입한 스타일러스 이벤트로 실제 엔진이 필기 · 도형 스냅 ·
  형광펜을 그리고 저장하는 것, PDF 노트 · 뷰어 · NAS 연결 · 설정 화면, WebDAV 서버와의 실제 동기화, 최적화된 릴리스 빌드에서
  노트 열기를 확인했습니다. 동기화 엔진 · NAS 클라이언트 · iPad 파일 호환은 JVM 테스트 35개로 검증했습니다.
- 실제 스타일러스 기기와 실제 NAS에서는 아직 손으로 검증하지 않았습니다. 문제가 있으면 이슈로 알려 주세요.

## 알려진 한계

- 캔버스는 CPU 타일 렌더러입니다(GPU 렌더러는 다음 단계).
- PDF로 내보낼 때 원본 PDF 페이지는 고해상도 이미지로 들어갑니다(필기는 벡터). PDF 목차는 표시하지 않습니다.
- WebDAV는 Basic 인증만 지원합니다. SMB는 저장소 제공자 앱을 통한 폴더 선택 방식입니다.
- 한 노트를 두 기기에서 동시에 고치면 노트 단위 충돌로 처리합니다.
