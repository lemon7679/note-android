Note for Android v0.1.1 — 편집기 제스처와 지우개 성능을 고친 업데이트입니다.

## 수정

- **확대/축소 · 이동 인식**: 천천히 핀치하거나 끌면 반응하지 않다가 갑자기 배율이 튀던 문제를 고쳤습니다.
  손가락 움직임을 처음 닿은 위치 기준으로 판단하고, 움직이기 시작하는 순간 튀지 않도록 기준점을 다시 잡습니다.
- 핀치를 마친 뒤 페이지가 관성으로 미끄러지지 않으며, 관성 스크롤은 마지막에 뗀 손가락 속도를 씁니다.
  손바닥으로 판정되어 취소된 터치는 무시합니다.
- **지우개 렉**: 형광펜처럼 굵고 긴 획을 지울 때 끊기던 문제를 줄였습니다. 지운 영역을 화면 갱신마다 한 번만,
  바뀐 부분만 다시 그립니다(펜을 뗄 때 · 실행 취소 때도 같은 방식).
